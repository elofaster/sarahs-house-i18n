# Sarah's House — Translation Mod

Ein inoffizieller mehrsprachiger Mod für Sarah's House (Windows, v0.11.2).

- Website: https://elofaster.github.io/sarahs-house-i18n/
- Download: https://github.com/elofaster/sarahs-house-i18n/releases/download/v2.8.9/SarahsHouse-i18n-v2.8.9.zip
- Neuestes Release: https://github.com/elofaster/sarahs-house-i18n/releases/latest

## Unterstütze das Spiel

Sarah's House ist ein kostenpflichtiges Spiel von AceStudio. Dieser Mod übersetzt es nur — wenn dir das Spiel gefällt, kaufe es und unterstütze die Entwickler:

## Installation

1. Entpacke das Release-Archiv in den Spielordner, neben `SarahsHouse.exe`.
2. Starte das Spiel — der erste Start kann 1–3 Minuten zur Einrichtung dauern.
3. Wähle deine Sprache im Menü im Spiel: Taste `F10` (oder das Sprachsymbol oben rechts).
