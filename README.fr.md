# Sarah's House — Translation Mod

Un mod multilingue non officiel pour Sarah's House (Windows, v0.11.6).

- Site web: https://elofaster.github.io/sarahs-house-i18n/
- Télécharger: https://github.com/elofaster/sarahs-house-i18n/releases/download/v2.9.1/SarahsHouse-i18n-v2.9.1.zip
- Dernière version: https://github.com/elofaster/sarahs-house-i18n/releases/latest

## Soutenez le jeu

Sarah's House est un jeu payant d'AceStudio. Ce mod ne fait que le traduire — si le jeu vous plaît, achetez-le et soutenez les développeurs :

- 🛒 Steam — https://store.steampowered.com/app/4712060/Sarahs_House
- 🎮 itch.io — https://ace-stud.itch.io/sarahs-house

## Installation

1. Décompressez l'archive de la version dans le dossier du jeu, à côté de `SarahsHouse.exe`.
2. Lancez le jeu : le premier démarrage peut prendre 1 à 3 minutes pour se préparer.
3. Choisissez votre langue dans le panneau en jeu : touche `F10` (ou l'icône de langue en haut à droite).
