# Sarah's House — Translation Mod

『Sarah's House』の非公式多言語 Mod（Windows、v0.11.2）。

- ウェブサイト: https://elofaster.github.io/sarahs-house-i18n/
- ダウンロード: https://github.com/elofaster/sarahs-house-i18n/releases/download/v2.9.0/SarahsHouse-i18n-v2.9.0.zip
- 最新リリース: https://github.com/elofaster/sarahs-house-i18n/releases/latest

## ゲームを応援する

『Sarah's House』は AceStudio による有料ゲームで、この Mod は翻訳のみを提供します。ゲームを気に入ったら、購入して開発者を応援してください：

- 🛒 Steam — https://store.steampowered.com/app/4712060/Sarahs_House
- 🎮 itch.io — https://ace-stud.itch.io/sarahs-house

## インストール

1. リリースのアーカイブを、`SarahsHouse.exe` と同じゲームフォルダーに展開します。
2. ゲームを起動します。初回起動は準備のため 1〜3 分かかることがあります。
3. ゲーム内のパネルで言語を選びます：`F10` キー（または右上の言語アイコン）。
