# Sarah's House — Translation Mod

Um mod multilíngue não oficial para Sarah's House (Windows, v0.11.2).

- Site: https://elofaster.github.io/sarahs-house-i18n/

## Instalação

1. Extraia o arquivo da versão para a pasta do jogo, ao lado de `SarahsHouse.exe`.
2. Inicie o jogo: a primeira inicialização pode levar de 1 a 3 minutos para preparar.
3. Escolha o seu idioma no painel dentro do jogo: tecla `F10` (ou o ícone de idioma no canto superior direito).
