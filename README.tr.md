- Web sitesi: https://elofaster.github.io/sarahs-house-i18n/

## Kurulum

1. Sürüm arşivini oyun klasörüne, `SarahsHouse.exe` dosyasının yanına çıkarın.
2. Oyunu başlatın: ilk açılış, hazırlık için 1–3 dakika sürebilir.
3. Dilinizi oyun içindeki panelden seçin: `F10` tuşu (veya sağ üst köşedeki dil simgesi).
