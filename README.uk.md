# Sarah's House — Translation Mod

Неофіційний багатомовний мод для Sarah's House (Windows, v0.11.2).

- Сайт: https://elofaster.github.io/sarahs-house-i18n/
- Завантажити: https://github.com/elofaster/sarahs-house-i18n/releases/download/v2.9.0/SarahsHouse-i18n-v2.9.0.zip
- Останній реліз: https://github.com/elofaster/sarahs-house-i18n/releases/latest

## Підтримайте гру

Sarah's House — платна гра від студії AceStudio. Цей мод лише перекладає її. Якщо гра вам подобається — придбайте її та підтримайте розробників:

- 🛒 Steam — https://store.steampowered.com/app/4712060/Sarahs_House
- 🎮 itch.io — https://ace-stud.itch.io/sarahs-house

## Встановлення

1. Розпакуйте архів релізу в папку з грою, поряд із `SarahsHouse.exe`.
2. Запустіть гру — перший запуск може тривати 1–3 хвилини на підготовку.
3. Оберіть мову на панелі прямо у грі: клавіша `F10` (або значок мови у правому верхньому куті).
