# Sarah's House — Bản Mod Dịch

Bản mod đa ngôn ngữ không chính thức cho Sarah's House (Windows, v0.11.6).

- Trang web: https://elofaster.github.io/sarahs-house-i18n/
- Tải xuống: https://github.com/elofaster/sarahs-house-i18n/releases/download/v2.9.1/SarahsHouse-i18n-v2.9.1.zip
- Bản phát hành mới nhất: https://github.com/elofaster/sarahs-house-i18n/releases/latest

## Ủng hộ trò chơi

Sarah's House là trò chơi trả phí của AceStudio. Bản mod này chỉ dịch trò chơi — nếu bạn thích game, hãy mua và ủng hộ nhà phát triển:

- 🛒 Steam — https://store.steampowered.com/app/4712060/Sarahs_House

## Cài đặt

1. Giải nén tệp phát hành vào thư mục trò chơi, cạnh `SarahsHouse.exe`.
2. Khởi động game — lần chạy đầu tiên có thể mất 1–3 phút để thiết lập.
3. Chọn ngôn ngữ trong bảng chọn của game: nhấn `F10` (hoặc biểu tượng ngôn ngữ ở góc trên bên phải).
