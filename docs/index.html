  1. Сделайте fork репозитория elofaster/sarahs-house-i18n.
  2. В mod/i18n/ создайте файл языка, например it.json, pl.json, ja.json или ko.json.
  3. В начале файла укажите ник автора ключом «__meta.author».
  4. Добавьте строки перевода в формате «english text»: «ваш текст».
  5. Откройте Pull Request в main — после ревью пакет появится на сайте.
{
  "__meta.author": "YourNick",
  "How are you?": "Как дела?"
}

Как поставить

Нужна Sarah’s House v0.11.2. Игра в архив не входит.

Скачать ZIP
  1. 01
    Скачать

  2. 02
    Распаковать

    архиватором в папку игры, рядом с SarahsHouse.exe

  3. 03
    Запуск

    первый старт 1–3 мин

  4. 04
    Меню языков

    открой переключатель в правом верхнем углу

  5. 05
    Выбор языка

    выбери нужный язык и играй
