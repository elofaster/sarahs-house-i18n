i18n language packs (EN -> target)
---------------------------------
Format: JSON object mapping English source strings to translated strings.

Author credit (required for community packs):
  put at the top of the file:  "__meta.author": "YourNick"
  This key is metadata only and should not be shown in-game.

Files:
  ru.json : Russian
  de.json / uk.json / es.json / fr.json : add translations, then pick in F10 panel
  en : no file needed (original English; credited as AceStudio on the site)

After editing, open a Pull Request to main.
